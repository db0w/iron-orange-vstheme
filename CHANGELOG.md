# Changelog

All notable changes to Iron Orange are documented here. This project follows [Semantic Versioning](https://semver.org/).

## 0.1.0

First release.

- **Iron Orange Dark:** bright copper editor with light orange title, activity and status bars, and a translucent gunmetal selection.
- **Iron Orange Light:** soft mandarin editor with orange title and activity bars and a deep copper status bar.
- Every syntax color reaches at least 4.5:1 against the editor background and on selected text, and the main text reaches at least 7:1. An automated check enforces this on every build.
- Full workbench coverage (453 colors per variant), the 16-color terminal palette, bracket pair colorization and semantic highlighting.
