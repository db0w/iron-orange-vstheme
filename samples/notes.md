# Iron Orange

## Metals used in the palette

- **Copper** for keywords and accents
- *Brass* for strings
- Steel for types, see [the palette](../src/palettes.mjs)

> Metallic tones, high-contrast text.

1. Build with `npm run build`
2. Check contrast with `npm run check`

```ts
const alloy = new Alloy('bronze', [copper, tin]);
```
